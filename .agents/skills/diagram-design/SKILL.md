# Diagram Design Skill

Translates complex engineering topologies into clean, accessible technical diagrams.

## Guidelines

- Use supported Mermaid diagram types: `flowchart TD`, `flowchart LR`, `sequenceDiagram`, `stateDiagram-v2`, `erDiagram`.
- Quote node labels containing special characters: `id["Label (Extra)"]`.
- Avoid HTML tags in node labels.
- Map system boundaries, databases, queues, and gateways cleanly.
