# Impeccable UI Polish Skill

Inspects and polishes frontend component UI/UX.

## Quality Checklist

- Check padding and margin scales (4px / 8px grid alignment).
- Verify WCAG 2.1 AA contrast ratios on badges, buttons, and muted text.
- Ensure focus rings and keyboard navigation states exist on all interactive elements.
- Verify consistent border-radius and dark-mode elevation tokens.
