# Humanizer Skill

Refactors AI-generated text, error messages, user prompts, and documentation into natural human prose.

## Rules

- Cut verbose introductory filler ("In today's fast-paced digital world...").
- Eliminate cliché words: "delve", "crucial beacon", "testament", "seamless tapestry".
- Prefer direct active voice: "Returns 403 when token is missing" instead of "It is vital to note that a 403 will be returned".
