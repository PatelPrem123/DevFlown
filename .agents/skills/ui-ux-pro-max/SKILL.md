# UI UX Pro Max Skill

Guides the implementation of professional, enterprise-grade React interfaces.

## Core Directives

- Build mobile-first, responsive layouts utilizing Tailwind CSS breakpoints (`sm`, `md`, `lg`, `xl`).
- Integrate smooth micro-transitions (`transition-all duration-200 ease-in-out`).
- Implement drag overlays with appropriate opacity (`opacity-80 scale-105 shadow-2xl`).
- Structure data-dense dashboards with clear visual weight and accessible typography scales.
